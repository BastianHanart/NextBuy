# NEXT_BUY

## Préambule
Le projet Next_buy est un projet IA/DATA, avec l'objectf de pouvoir prédire les différents éléments liés au achats dans un supermarché.<br>
Notre but, comprendre, analyser interpréter les données d'un supermarché. Pour ensuite construire des modèles d'IA qui permette de prédire et d'aider à améliorer et à optimiser les ventes du dit supermarché.

## Installer notre projet

Pour pouvoir utiliser notre projet il faut d'abord bien savoir comment tout initialer !
Après avoir installer tous les fichiers de ce répertoire, lancez un terminal et mettez-vous dans le fichier à la racine du projet.
Ici, effectuez les commandes suivantes :
- "python3 -m venv Myvenv"
- "source Myvenv/bin/activate"
- "pip install requirements.txt"

Dans requirements se trouve
Si cette étape est totalement réussi. Vous avez réussi à initialiser le projet et allez pouvoir l'utiliser.
